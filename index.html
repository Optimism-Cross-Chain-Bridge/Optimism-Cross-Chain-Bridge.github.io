What is Optimism Cross Chain?

Optimism is the ecosystem behind OP Mainnet, its flagship Ethereum Layer 2 blockchain; the official bridge routes supported transfers between Ethereum and OP Mainnet through app.optimism.io.

How Optimism Cross Chain works

  1. Open the gatewayUse the official app URL and verify the app.optimism.io domain before connecting a wallet.
  2. Connect walletSelect your Ethereum wallet and confirm you are on the intended source network.
  3. Choose asset and routePick the supported token, amount, source chain, and OP Mainnet destination.
  4. Review and confirmCheck gas, recipient, timing, and token details before signing the transaction.

Before you bridge

Official app-first route

The destination should be the Optimism bridge interface on app.optimism.io, not a lookalike domain.

Standard Bridge design

Optimism docs describe the Standard Bridge as supporting ETH and most ERC-20 transfers between Ethereum and OP Mainnet.

Ethereum-aligned settlement

OP Mainnet is an Ethereum Layer 2; ethereum.org explains how Layer 2 networks extend Ethereum while relying on its base layer.

Optimism Cross Chain FAQ

What is optimism cross chain used for?

It is used to find the official Optimism bridge path for moving supported assets between Ethereum and OP Mainnet.

Is optimism cross chain the official bridge?

This landing page is not the official app; the official action happens at app.optimism.io.

How long does optimism cross chain bridging take?

Optimism docs state Ethereum-to-OP Mainnet Standard Bridge transfers usually complete in 1-3 minutes, while OP Mainnet-to-Ethereum withdrawals complete after the 7-day challenge period.

Which assets can optimism cross chain route?

The Standard Bridge supports ETH and most ERC-20 tokens, but availability depends on the selected token, bridge route, and token representation.

Can optimism cross chain send assets back to Ethereum?

Yes, supported assets can be withdrawn from OP Mainnet to Ethereum, but users should review the longer withdrawal timing and required confirmations before signing.
